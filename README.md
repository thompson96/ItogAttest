# Курс криптовалют к USD

Приложение с графическим интерфейсом на Python для получения актуальных курсов криптовалют по отношению к доллару США (USD) с использованием CoinGecko API.

## Возможности

- Выбор криптовалюты из выпадающего списка.
- Получение актуального курса через CoinGecko API.
- Отображение результата в информационном окне.
- Вывод сообщения при возникновении ошибки.

## Требования

- Python 3.
- Доступ к интернету.
- API-ключ CoinGecko Demo.

## Установка

1. Скачайте проект и откройте его папку.
2. Установите необходимые библиотеки:

   `python -m pip install -r requirements.txt`

3. Создайте в корневой папке проекта файл `.env` и добавьте в него свой API-ключ CoinGecko:

   `COINGECKO_API_KEY=ваш_api_ключ`

   Название переменной должно совпадать с используемым в исходном коде приложения.

## Запуск

Запустите приложение командой:

`python main.py`

## Использование

1. Выберите криптовалюту из выпадающего списка.
2. Нажмите кнопку «Получить курс к USD».
3. Ознакомьтесь с курсом в появившемся информационном окне.

Для получения курса другой криптовалюты повторите действия.
